告别"AI 审美"，

Frontend Design Plugin 是 Anthropic 官方出品的前端设计增强工具，它的核心使命只有一件事：让 Claude 生成的界面不再千篇一律。

Anthropic Verified 324,030 次安装 适用于 Claude Code

打开任意一个 AI 生成的落地页，你大概率会看到：深紫色渐变背景、Inter 字体、整整齐齐的三列卡片、一个蓝色的 CTA 按钮。这套组合出现的频率高到有了专属称谓——"AI Slop"，AI 浆糊。

这不是模型的失误，而是训练数据的必然结果。AI 学习了互联网上数百万个网页的公约数，因此它的"默认风格"就是这些网页的最大公约数——安全、通用、无记忆点。

Frontend Design Plugin 的出现，正是为了打破这个局面。它在 Claude 动手写代码之前强制插入一个设计思维阶段：这个界面是给谁用的？应该传达什么情绪？用什么字体、什么色调，能让它被记住？

设计解析

复古未来主义（Retro Futurism）借用了1970–80年代电子显示设备的视觉语言：橙色荧光、IBM Plex Mono 等宽字体、Bebas Neue 大字重数字、CRT 扫描线纹理。配色只有深棕黑底 + 橙红 + 琥珀色数字，没有任何多余颜色介入。适合体育直播、电竞、游戏、机械控仪表盘。

设计的本质是做选择。Frontend Design Plugin 的价值不在于它会做什么，而在于它会拒绝什么——它拒绝了"差不多就行"。

这三个示例只是冰山一角。Plugin 文档中列举的风格方向还包括：Maximalist 极繁主义、Organic/Natural 有机自然、Editorial/Magazine 杂志编辑、Art Deco 装饰艺术、Soft/Pastel 柔和粉彩、Industrial/Utilitarian 工业实用……每一种都有对应的字体选择逻辑、配色策略、和排版语法。

Frontend Design Plugin 的安装方式：在 Claude Code 中直接使用，或在 claude.com/plugins/frontend-design 页面点击安装。安装后，每当你要求 Claude 构建界面组件、落地页、仪表盘，或任何视觉输出时，Plugin 会自动激活——你不需要每次都提醒它"请注意设计质量"。
